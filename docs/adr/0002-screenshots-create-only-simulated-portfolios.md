# Screenshots create only Simulated Portfolios

Screenshot import (read by a vision model, then reviewed) can create a Simulated Portfolio or replace one's Positions, but it never writes into an Account. An Account's holdings come only from Schwab, so an Account never has two competing sources and there's no merge rule for when they disagree. A screenshot of your real holdings is still useful: it becomes a Simulated Portfolio you can run Scenarios on, for example before Schwab approves the app.
