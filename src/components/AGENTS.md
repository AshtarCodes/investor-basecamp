# Components

shadcn/ui is the component source. `components.json` is its config. Add a component with the shadcn CLI (`shadcn add …`); that writes `src/components/ui/<name>.tsx`. Those files are source: change the look by editing them.

App components sit next to `ui/`. `cn` comes from `src/lib/utils.ts`.

Component tests follow the component layer in `tests/AGENTS.md`.
